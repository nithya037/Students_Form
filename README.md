Project Description: Student Registration Form with Dynamic Table

Create a Student Registration Form using HTML, CSS, and JavaScript. The form should collect user details and validate all required fields before submission.

When the user clicks the Submit button, the entered details should be dynamically displayed in a table below the form. Each submitted record should have a Delete button to remove individual records from the table.

Requirements:
- Create input fields for Name, Email, Password, and Bio.
- Validate all input fields.
- Require a minimum of 6 characters for the password.
- Limit the Bio field to 200 characters.
- Display a live character counter for the Bio field.
- Enable the Submit button only when all fields are valid.
- Display submitted details in a table below the form.
- Add a Delete button for each table row.
- Display a success message after saving the details.
Expected Outcome:

A simple, interactive registration form that validates user inputs, dynamically displays submitted details in a table, and allows users to delete individual records using JavaScript DOM manipulation.
